# ICT PD Array Matrix — Premium & Discount Trade Execution Framework + Free PDF

**Source:** [https://innercircletrader.net/tutorials/ict-pd-array-key-to-trade-execution/](https://innercircletrader.net/tutorials/ict-pd-array-key-to-trade-execution/)

![ICT PD Array Matrix diagram showing premium and discount zones with the eight institutional trigger tools](https://www.innercircletrader.net/wp-content/uploads/2024/01/ICT-PD-array-1.png)

The ICT PD Array stands for “Premium and Discount Arrangement” — the canonical framework Michael Huddleston taught for choosing where to enter a trade. The PD Array is not a single tool. It is a checklist of eight institutional trigger tools, each placed in either the premium zone (top half of a dealing range) or the discount zone (bottom half), used to identify the optimal price for buying and selling.

I use the PD Array on every trade I take. It is the input to the daily bias call, the input to every kill-zone setup, and the framework I use to decide whether a particular fair value gap, order block, or breaker is worth trading in the current context. Without the PD Array, every other ICT setup is just a chart pattern in isolation.

To find the PD Arrays on any chart, draw a fibonacci retracement from an established old high to an established old low — using the dealing range as the anchor. The 50% line splits the range into premium (top half) and discount (bottom half). The eight ICT trigger tools then arrange themselves in either zone based on direction, and the right tool in the right zone is the entry.

This guide is the canonical breakdown of the ICT PD Array Matrix — what it is, how to identify the premium and discount zones, the eight tools in each direction, the step-by-step trade flow, the common mistakes I see traders make, and the answers to the questions I get most often.

#### What is the ICT PD Array Matrix?

The ICT PD Array Matrix is the arrangement of eight ICT trade-entry tools across the premium and discount zones of a dealing range. The matrix is a checklist — when price reaches a level inside the right zone where one of the eight tools fires, that confluence is the trade.

The logic is simple. As a seller, I always want to sell at a premium price. As a buyer, I always want to buy at a discounted price. The PD Array Matrix shows me where premium and discount sit on the chart, and which tool to use in each zone to time the entry precisely.

![ICT PD Arrays diagram showing the premium zone above 50% and the discount zone below 50% with the institutional tools arranged in each](https://innercircletrader.net/wp-content/uploads/2024/01/ICT-PD-arrays.png)

**Elements of ICT PD Arrays**

The PD Array contains the following eight ICT trigger tools — each one a complete model in its own right:

  1. [ICT Fair Value Gap](<https://innercircletrader.net/tutorials/fair-value-gap-trading-strategy/>) (FVG)
  2. [ICT Inverse Fair Value Gap](<https://innercircletrader.net/tutorials/ict-inversion-fair-value-gap/>) (IFVG)
  3. [ICT Order Block](<https://innercircletrader.net/tutorials/ict-order-block/>)
  4. [ICT Breaker Block](<https://innercircletrader.net/tutorials/ict-breaker-block-trading/>)
  5. [ICT Mitigation Block](<https://innercircletrader.net/tutorials/ict-mitigation-block-explained/>)
  6. [ICT Unicorn Model](<https://innercircletrader.net/tutorials/ict-unicorn-model/>)
  7. ICT NWOG (New Week Opening Gap)
  8. ICT NDOG (New Day Opening Gap)

When more than one of these tools sits at the same price level in the correct zone, the confluence is meaningfully stronger than any single tool alone.

#### How to Identify the ICT PD Arrays

To identify the premium and discount zones on any chart, plot the fibonacci retracement tool with these three levels:

  * **1.0** — Start (the upper end of the dealing range)
  * **0.5** — Equilibrium (the midpoint, where premium and discount split)
  * **0.0** — End (the lower end of the dealing range)

Plot the fibonacci from an established old high to an established old low. The 50% level is the midpoint. The area above the 50% line on the chart is the **premium zone**. The area below the 50% line is the **discount zone**.

![ICT PD Array fibonacci setup chart showing premium zone above 50% and discount zone below 50% on the dealing range](https://www.innercircletrader.net/wp-content/uploads/2024/01/ICT-PD-array.png)

#### Types of ICT PD Arrays

By price-movement direction, PD Arrays split into two types:

#### Bullish PD Arrays (Discount Zone)

Bullish PD Arrays are the arrangement of ICT trade-execution tools in the discount zone (the bottom half of the dealing range). I use bullish PD Arrays to identify buy entries when the daily bias is bullish.

  1. Bullish Fair Value Gap (BISI — Buy-side Imbalance Sell-side Inefficiency)
  2. Bullish Order Block
  3. Bullish Breaker Block
  4. Bullish Mitigation Block
  5. Bullish Inverse Fair Value Gap
  6. ICT NDOG (in a bullish context)
  7. ICT NWOG (in a bullish context)
  8. Bullish ICT Unicorn Model

If multiple bullish trigger tools sit at the same price in the discount zone, that confluence is a high-probability buy entry. I wait for price to test the level and reject — and that rejection is the buy.

![Bullish ICT PD Array example chart — multiple bullish trigger tools stacked in the discount zone marking a high-probability buy entry](https://www.innercircletrader.net/wp-content/uploads/2024/01/Bullish-ICT-PD-array.png)

#### Bearish PD Arrays (Premium Zone)

Bearish PD Arrays are the arrangement of ICT trade-execution tools in the premium zone (the top half of the dealing range). I use bearish PD Arrays to identify sell entries when the daily bias is bearish.

  1. Bearish Fair Value Gap (SIBI — Sell-side Imbalance Buy-side Inefficiency)
  2. Bearish Order Block
  3. Bearish Breaker Block
  4. Bearish Mitigation Block
  5. Bearish Inverse Fair Value Gap
  6. ICT NDOG (in a bearish context)
  7. ICT NWOG (in a bearish context)
  8. Bearish ICT Unicorn Model

Same rule — multiple bearish trigger tools stacked at the same price in the premium zone is a high-probability sell entry. I wait for price to tap the level and reject downward.

#### Step-by-Step PD Array Trade Flow

This is the exact sequence I run when trading inside the PD Array framework. Save it, print it, do not skip a step.

  1. **Identify the dealing range** on the higher timeframe (daily, 4-hour, or 1-hour). Mark the established swing high and swing low that have already swept liquidity.
  2. **Plot the fibonacci** from the swing high to the swing low, with levels at 1.0, 0.5, and 0.0.
  3. **Mark premium and discount zones** on the chart — above 50% is premium, below 50% is discount.
  4. **Set the daily bias** using [ICT Daily Bias](<https://innercircletrader.net/tutorials/ict-daily-bias-explained/>). If bullish, hunt for buy setups in the discount zone. If bearish, hunt for sell setups in the premium zone.
  5. **Wait for price to enter the correct zone** for your bias direction.
  6. **Drop to the lower timeframe** (15-minute, 5-minute, or 3-minute) and watch for one or more PD Array trigger tools to print.
  7. **Confirm with a Market Structure Shift** on the lower timeframe in the direction of your bias.
  8. **Identify the strongest PD Array** at the level — when multiple tools stack (FVG + OB, OB + Breaker, etc.), confluence makes the entry stronger.
  9. **Execute the trade** on the retest of the PD Array, with stop loss beyond the structural extreme that preceded the MSS.
  10. **Take profit** at the opposite end of the dealing range (the 1.0 level for buys, the 0.0 level for sells), or at the next significant draw on liquidity.

#### How to Use ICT PD Arrays

PD Arrays serve two major purposes for ICT traders.

**(I) Daily bias identification.** If price has already shifted structure to the downside and is now in the premium zone, the bias is bearish — hunt for sell setups. If price has already shifted to the upside and is now in the discount zone, the bias is bullish — hunt for buy setups. The combination of structural direction and current zone tells me which side of the market to trade.

**(II) Trade execution.** When the daily bias is bearish and price is in the premium zone, I drop to the lower timeframe, wait for a Market Structure Shift, and find a bearish PD Array at the level to execute the sell. When the bias is bullish and price is in the discount zone, the same workflow applies in the opposite direction — wait for the MSS, find a bullish PD Array, and execute the buy.

#### Best Time Frame for ICT PD Arrays

The right timeframe depends on the use case.

For **daily bias identification** , the 1-day timeframe is the canonical reference. Daily PD Arrays produce the most reliable bias reads because they reflect the institutional positioning over many sessions.

For **trade entry execution** , drop to the lower timeframes — 15-minute and 5-minute. Lower-timeframe PD Arrays inside a higher-timeframe zone give the precise entry timing.

The two timeframes work together. Higher-timeframe PD Array sets the directional context; lower-timeframe PD Array fires the entry.

#### Best Trading Pair for ICT PD Arrays

ICT PD Arrays were originally developed and tested on US index futures — **NASDAQ 100 (NQ Futures)** and the **E-mini S &P 500 (ES Futures)**. These remain the cleanest instruments for the framework because the time-of-day delivery on US index futures is the most predictable.

The PD Array framework also works very well on the major forex pairs and metals: **GBP/USD** , **EUR/USD** , and **XAU/USD** (Gold). Same fibonacci-based zones, same eight trigger tools — just different volatility profiles.

For US-based futures traders, ES and NQ are CFTC-regulated futures and execute through a US futures broker (NinjaTrader, AMP, Tradovate, or a prop firm such as Topstep). TradingView is for chart analysis only.

#### Common Mistakes I See Traders Make on PD Arrays

Five mistakes account for the majority of failed PD Array trades I see in the comments. Avoid these and the framework converts at a much higher rate.

  1. **Trading the wrong PD Array in the wrong zone.** Bullish PD Arrays only work in the discount zone. Bearish PD Arrays only work in the premium zone. A bullish FVG in the premium zone is not a buy entry — it is just a fair value gap waiting to fail.
  2. **Skipping the dealing range marking.** Without an established swing high and swing low (each having swept liquidity), the dealing range is not valid. Without the dealing range, the fibonacci has no anchor and the premium / discount zones are guesses.
  3. **Trading PD Arrays against the daily bias.** The PD Array framework requires bias alignment. A discount-zone bullish setup against a bearish daily bias is a coin flip at best.
  4. **Treating any FVG, OB, or Breaker as a PD Array.** The matrix has eight specific tools, and each must be validated against its own rules (Order Block engulf, Breaker liquidity sweep, Mitigation OB hold, etc.). Loose pattern recognition is the fastest way to misread the matrix.
  5. **Forcing a single tool when no confluence exists.** The strongest PD Array setups stack two or more tools at the same level. A lone FVG in the discount zone is tradable, but a lone FVG plus a bullish Order Block plus a Breaker stacked at the same level is dramatically higher probability.

#### FAQs About the ICT PD Array

**What is the ICT PD Array?**

ICT PD Array stands for “Premium and Discount Arrangement” — the canonical framework for choosing trade entry points in the ICT method. It is a matrix of eight institutional trigger tools (FVG, IFVG, Order Block, Breaker, Mitigation, Unicorn, NDOG, NWOG) arranged across the premium and discount zones of a dealing range.

**How do I identify premium and discount zones?**

Plot the fibonacci retracement tool from an established old high to an established old low, with levels at 1.0, 0.5, and 0.0. Above the 50% line is the premium zone. Below the 50% line is the discount zone.

**What are the eight ICT PD Array trigger tools?**

Fair Value Gap, Inverse Fair Value Gap, Order Block, Breaker Block, Mitigation Block, Unicorn Model, NDOG (New Day Opening Gap), and NWOG (New Week Opening Gap). Each one fires entries when price taps it inside the correct zone.

**What is a bullish PD Array?**

A bullish PD Array is any of the eight trigger tools positioned in the discount zone (below the 50% fibonacci line). It is used to identify buy entries when the daily bias is bullish.

**What is a bearish PD Array?**

A bearish PD Array is any of the eight trigger tools positioned in the premium zone (above the 50% fibonacci line). It is used to identify sell entries when the daily bias is bearish.

**How do I use PD Arrays for daily bias?**

Read the structural direction and the current zone together. Structure shift to the upside plus price in the discount zone equals bullish bias. Structure shift to the downside plus price in the premium zone equals bearish bias.

**What is the best timeframe for PD Arrays?**

1-day for daily bias identification. 15-minute or 5-minute for trade execution inside a higher-timeframe zone. The higher TF gives context; the lower TF fires the entry.

**What instruments work best with PD Arrays?**

US index futures (NASDAQ 100 / NQ and E-mini S&P 500 / ES) produce the cleanest PD Arrays. Major forex pairs (GBP/USD, EUR/USD) and Gold (XAU/USD) also respect the same fibonacci zones and trigger tools.

**Should I use one PD Array tool or stack multiple?**

Stack when possible. A lone FVG or OB inside the right zone is tradable, but the strongest setups have two or more PD Array tools at the same level — the confluence dramatically improves the win rate.
