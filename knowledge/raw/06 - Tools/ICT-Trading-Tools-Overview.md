# Real-time tools to find when liquidity is engineered

Hand-coded by Ayub Rana. Three browser-based tools that show when institutional traders are active and where smart-money setups form.

**Live tools (open in browser — times auto-detect your timezone):**

| Tool | What it shows | Link |
|---|---|---|
| **ICT Kill Zones** | The 4 high-probability windows (Asian, London, New York AM, New York PM), live status, countdown to next window | [Open tool / guide](https://innercircletrader.net/tutorials/master-ict-kill-zones/) |
| **ICT Macro Times** | 20-minute macro windows where algorithms run liquidity sweeps | [Open tool / guide](https://innercircletrader.net/tutorials/ict-macro-time-based-strategy/) |
| **Forex Market Hours** | Sydney, Tokyo, London & New York sessions + London/NY overlap | [Open tool](https://innercircletrader.net/tools/forex-market-hours/) |

## Which tool to use

- **New to ICT** — start with **Kill Zones** to learn which time windows institutions care about.
- **Intraday US indices (NQ/ES)** — use **Macro Times** (20-minute windows where most setups print).
- **Forex pairs** — use **Forex Market Hours**; London/New York overlap is peak volatility for EUR/USD, GBP/USD, XAU/USD.
