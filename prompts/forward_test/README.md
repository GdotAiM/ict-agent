# Forward-Testing Prompt Set  
## Same ICT doctrine, applied to the *coming* week

These prompts mirror the back-test set (`from_video_2026_08_15`) but are written for **live / forward** use:

- Run on the weekend *before* the new week opens.
- Produce the Weekly Narrative and Daily Bias *before* London / 09:30 ET.
- The agent must anticipate, not react.
- After the week closes you can compare the forward artefacts with what actually occurred (and with any new ICT commentary).

All rules remain grounded in “The Week In The Life Cycle Of Price” (15 Aug 2026).
